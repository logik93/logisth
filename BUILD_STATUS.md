# logisth 1.0.11 native release

The release workflow tests Windows x86-64, Linux x86-64 and Windows
AddressSanitizer before publishing the first two packages. It then builds and
appends macOS Universal to the same release. Each package includes VST3,
CLAP and Standalone.
