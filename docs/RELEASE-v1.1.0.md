# logisth 1.1

- **Sample** shows the live playback percentage between START and END. Loop IN and OUT have separate grips, including when their endpoints line up.
- **Graphic EQ** adds 12, 24, 36 and 48 dB/octave slopes for High-pass and Low-pass. The response plot uses the configured filter order and host sample rate.
- **PRE** and **POST** can be enabled independently, enabled together or switched off to leave the EQ curve visible.
