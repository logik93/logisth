# logisth 1.0.0

The Sample page now has editable, automatable **START** and **END** percentages for each of the six players. Drag either waveform handle to record that endpoint. Labels have their own space above the playhead and stay readable when the handles meet. The AP always flexin'! skin groups its logo and caption in the header and About panel.

A long sampler or granular note can now continue when a host inserts another instrument and resumes the same playing timeline. MIDI OUT tracks each instance's outgoing keys and sustain pedal. Asynchronous sample imports respect a newer drop, clear or preset recall on the same player.

The release includes VST3, CLAP and Standalone builds, both English manuals, and a reproducible two-instance playback test. The existing 1,089 host parameters and project schema are preserved.
