# logisth 1.0.6

Windows Standalone can use installed ASIO drivers. Open **Audio/MIDI
Settings**, select **ASIO** as the audio device type, then select your
audio interface and outputs.

This release includes the FL Studio Master Pitch correction and the Bend and
Mod automation from 1.0.5. See the English manuals for setup and
[the ASIO verification notes](https://github.com/logik93/logisth/blob/v1.0.6/docs/REVIEW-v1.0.6.md).
