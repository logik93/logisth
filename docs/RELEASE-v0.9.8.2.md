# logisth v0.9.8.2

The header MODULATION +/- button folds the complete Mod Env 1/2, LFO 1/2 and
Misc 1/2 row. The actual window shrinks from 1240 x 860 to 1240 x 640 at 100%,
moving the keyboard and footer up. Modulation, MIDI and host automation continue.
The active layout, exact scale and window size survive editor reopen; previous
appearance files open expanded. Fractional scaling remains uniform.

SETTINGS > SKIN includes twenty original generated background images, two for
each of the ten standard palettes. They are embedded and available offline.
Choose an image, adjust IMAGE MIX/PANELS and save a portable theme with
COLOURS > SAVE AS. The palette, fonts, header SVG and AP artwork are preserved.
The backgrounds ZIP includes all unchanged PNG originals and a catalogue.
The leftover top highlight line is removed, including the grid's edge line.

The 1084 sound parameters and audio DSP remain unchanged. English user/technical
manuals and compact-layout/background regression evidence are updated. Formats:
VST3, CLAP, Standalone. Windows/Linux publish first; macOS Universal follows in
the same release. Original-code MIT and open-source notices remain included.
