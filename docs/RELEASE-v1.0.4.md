# logisth 1.0.4

Pitch bend from a DAW or MIDI controller now uses **INPUT / st** to translate
wheel position into a pitch change. The default input range is ±2 semitones.
Set it to match your DAW or controller. **BEND / st** caps the pitch change
and the on-screen wheel shows the applied bend relative to that limit.

The Windows x86-64, Linux x86-64 and macOS Universal packages include VST3,
CLAP and Standalone. The English user and technical manuals cover the new control.
