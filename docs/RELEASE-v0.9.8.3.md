# logisth v0.9.8.3

Distortion adds optional **Multiband** routing: 1–4 bands, graphical/numeric
crossovers, independent module On/Off/model/Drive/Mix, reassignable headers and
pre/post stereo spectra with 0–6 dB/oct display tilt. A band bypass preserves its
clean frequency range. One band processes the full range. Legacy retains the
existing four serial stages and is the default for older patches. Routing,
count and crossovers save/automate; five parameters append after the prior 1084.

Gradient backgrounds are visible inside the panels and screen. SETTINGS > SKIN
adds GRADIENT and GRID 0–100% sliders. Values persist in drafts and portable
themes; old files remain readable. Slider changes repaint without rebuilding
controls. ABOUT credits mixedbytrzy for testing, the modulation-menu idea and
other contributions.

120 runtime reconstruction cases cover 1–4 bands at 44.1/48/96 kHz. Evidence also
covers band isolation, stereo independence, exact Legacy parity, coefficient and
routing changes, inactive CPU bypass, capture lifecycle, preset recall and actual
GUI interactions. English user/technical manuals and raw evidence are included.
Formats: VST3, CLAP, Standalone. Windows/Linux publish first, macOS Universal
joins the same release afterward. MIT license and actual open-source notices
remain included. Earlier published release assets are unchanged.
