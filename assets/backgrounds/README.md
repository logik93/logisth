# logisth factory backgrounds

Twenty original PNG backgrounds generated with AI image generation for
logisth 0.9.8.2, two for each standard theme. See catalogue.json for the theme,
artwork name and original PNG filename. Images are supplied unchanged at their
generated resolution (1536 x 1024). They contain no logos or lettering.

Use SETTINGS > SKIN > factory background chooser in logisth. No separate file
installation is needed: all twenty images are embedded in the instrument.
The supplied originals can also be selected with LOAD IMAGE. IMAGE MIX controls
artwork strength; PANELS controls the visibility beneath control panels.
COLOURS > SAVE AS embeds the chosen PNG in a portable theme JSON.
The palette, font and AP/standard logos remain separate from the background.

The project distributes these generated assets under its MIT terms; see LICENSE.
