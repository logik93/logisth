# logisth 1.0.10

- Stereo **Flanger** starts after Chorus. Reorder it with the rack handle, the row menu or Alt+Up/Down. Controls include delay, depth, rate, stereo width, bipolar feedback, damping and mix.
- Granular **Playback** now controls the time factor, source rate, grain tuning and interpolation. In Cloud, Scan determines whether the source moves. In Granulizer, Time Hold freezes the grain head.
- Sampler **Paul Stretch** adds a Paulstretch-style phase diffusion mode with a 0.5x, 1x and 2x ratio mixer. It is implemented in logisth using Signalsmith Linear's FFT.
- The virtual keyboard checks the displayed state against the latest MIDI state and responds to All Sound Off. The Chords caption uses glyphs supported by the interface and aligns all eight voice labels.
- The Apache site package keeps direct platform downloads available when PHP is unreachable and can load current GitHub manuals into the themed reader.
